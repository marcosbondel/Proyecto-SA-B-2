# customer-service / domain

Entities, value objects, domain errors and invariants for the customer identity: registration, identity-document references, name, username, email, address and date of birth.

This layer imports nothing — not another layer, not a framework, not another
service. That is enforced by lint, not by convention (FR-006, FR-007).
